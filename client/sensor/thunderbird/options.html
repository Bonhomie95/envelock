ENVELOCK

Envelock sensor for Thunderbird

Tells Envelock which messages you open here, so it can tell you when a message was read somewhere else.

Add a mailbox

In the Envelock dashboard, open the mailbox and choose Add a device. Type the code it shows you here. The mailbox must be one of the accounts set up in this Thunderbird.

What this add-on sees

The Message-ID of each message you open, and that Thunderbird is running. Never the message itself, never your password.
